PALOMA BAY — a sun-soaked crime story. An open-world 3D action game built from scratch in raw WebGL2 (no libraries, no assets). Theo Marchetti drives the night taxi and owes the Vireo family forty thousand. Eight missions, three choices, three endings. Five weapons, five-star police with a helicopter spotlight, a living beachfront city with palm-lined streets, billboards, a park, and a full map with GPS.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://localhost:8000 in desktop Chrome. WASD drives and walks, mouse aims, click shoots, 1–5 switch weapons, M opens the map.
